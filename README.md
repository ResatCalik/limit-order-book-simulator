# Limit Order Book Simulator

This project is an educational stock exchange simulator.

## Goal
To understand how a limit order book works and how orders are stored, prioritized, and later matched.

## Current Scope
- Create buy and sell orders
- Validate incoming order data
- Store orders inside an order book
- Sort buy and sell orders by price
- Add unit tests
- Run tests automatically with GitHub Actions

## Future Scope
- Matching engine
- Partial fill
- Cancel order
- Trade model
- Market data stream
- Docker support

## Out of Scope
- Real brokerage integration
- Real market connectivity
- Investment advice
